# SQL Exploratory Data Analysis: Layoffs 2022

## Overview
This project explores a cleaned dataset of 2022 global company layoffs 
using SQL to uncover key trends and answer business questions. This 
builds on my SQL Data Cleaning Project, which prepared the raw data 
for this analysis.

## Key Questions Answered
- How many total layoffs occurred, and over what time period?
- Which companies had the highest number of layoffs?
- Which industries and countries were hit hardest?
- What was the worst month for layoffs?
- Which companies shut down entirely (100% layoffs)?
- Is there a relationship between funding raised and layoff size?
